# 🐱 Три кота: Учимся считать!

Веб-игра (PWA) для обучения ребёнка 5+ лет математике. Ведут игру **Три кота**:
**Компот** (старший брат в бирюзовом колпаке), **Коржик** (средний брат в матроске) и **Карамелька** (младшая сестрёнка с красным бантиком).

Работает без интернета, ставится на iPad / iPhone / Android как приложение.

## Что внутри

| Тема | Уровни |
|---|---|
| 123 Считаем | до 5 → до 10 → до 20 → десятки до 50 → до 100 |
| <> Больше-меньше | до 10 → до 20 → до 100 → сравнение примеров |
| + Сложение | до 5 → до 10 (с картинками / в уме) → через десяток → до 100 → двузначные |
| − Вычитание | то же для вычитания |
| □ Найди число | состав числа → до 20 → до 100 → × и ÷ с пропуском |
| 🧩 Закономерности | +1/−1 → шагами → большие шаги → ×2, растущие шаги, чередование |
| × Умножение | по 2 → по 2, 3, 5, 10 → до 5×5 → вся таблица → двузначное × однозначное |
| ÷ Деление | «раздели между котятами» → до 5 → до 50 → вся таблица → большие |
| 📖 Задачки | текстовые задачи: +/− до 10 и 20, × и ÷, в 2 действия |
| 🎓 Профессор | порядок действий, скобки, загадки (половина, удвоение, «задумал число», «сколько лапок у 7 котят») |

- **Мягкие котячьи звуки**: у Компота, Коржика и Карамельки разные нежные мультяшные голоса («миу-миу-миу!»), плюс приятные игровые мелодии без резкой системной озвучки.
- **Наглядность**: предметы группами по 5, десятки-«палочки», тарелки для умножения. В счёте можно нажимать на предметы — они нумеруются. В делении можно нажимать на предметы и раздавать их котятам по очереди.
- **Мягкие ошибки**: 1-я ошибка → картинка, 2-я → подсказка 💡, 3-я → котёнок показывает ответ.
- **Прогресс**: раунд из 8 заданий, 1–3 звезды. Следующий уровень открывается за ★★.
- **Награда**: за каждый верный ответ с первой попытки — рыбка 🐟 в аквариум; по мере накопления приплывают новые жители.
- **Для взрослых**: удерживайте ⚙️ на главном экране 1,5 секунды — звуки, число заданий, «открыть все уровни», сброс.

## Запуск локально

```bash
python3 -m http.server 8000
```

Откройте http://localhost:8000. Сборки нет — чистые HTML/CSS/JS.

## Публикация (GitHub Pages)

1. Влейте код в `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` опубликует игру на `https://<user>.github.io/kitten-math/`.

Подойдёт любой статический хостинг с HTTPS (Netlify, Cloudflare Pages, Vercel) — PWA требует HTTPS.

## Установка на iPad / iPhone

Откройте ссылку в **Safari** → кнопка «Поделиться» → **«На экран „Домой“»**. Игра откроется на весь экран и будет работать офлайн.
На Android: Chrome → меню → «Установить приложение».

## Обновление

После изменения файлов увеличьте `CACHE` в `sw.js` (`kitten-math-v2` …), чтобы установленные копии подхватили новую версию.
